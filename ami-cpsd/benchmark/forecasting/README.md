# Track 4 — Time-Series Forecasting

This directory is a stub for future forecasting models (e.g., LSTM-Forecast, TCN, Informer, PatchTST) operating on the AMI-CPSD v2.0 dataset.

## Objective
Train models to forecast future physical metrics (voltage, current, power) over time horizons $t + 1, \dots, t + H$ to support proactive anomalies detection and grid planning.
