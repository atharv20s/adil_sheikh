# Track 6 — Federated Learning

This directory is a stub for future federated learning algorithms (e.g., FedAvg, FedProx, FedNova) operating on the AMI-CPSD v2.0 dataset.

## Objective
Train intrusion detection models collaboratively across multiple simulated local microgrids/substations/smart meters without centralizing raw physical/cyber logs, preserving consumer privacy.
