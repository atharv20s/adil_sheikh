# Track 8 — Explainable AI (XAI)

This directory is a stub for future explainability frameworks (e.g., SHAP, LIME, Integrated Gradients, Grad-CAM) operating on the AMI-CPSD v2.0 benchmark models.

## Objective
Provide auditable explanation mappings linking specific physical anomalies (voltage deviations, power imbalances) or network behavior (latency spikes, Byzantine votes) to model intrusion alerts.
